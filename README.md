## Projects

### 1. Word2Vec from Scratch
**Status:** Completed

Implemented the Skip-Gram with Negative Sampling (SGNS) algorithm in PyTorch to learn distributed word representations without relying on pre-trained embeddings.

**Key concepts explored**
- Tokenization and vocabulary construction
- Context windows
- Skip-Gram architecture
- Negative Sampling
- Embedding matrices
- Backpropagation through embeddings
- Training word vectors from raw text

**Technologies**
- Python
- PyTorch
- NumPy
